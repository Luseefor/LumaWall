# LumaWall

LumaWall is an independently implemented native macOS wallpaper engine. It does
not include or copy Phosphene source code, branding, identifiers, storage formats,
or assets.

The first clean-room milestone contains the original domain model, per-display
composition model, and energy policy. The next milestone adds LumaWall's own
AVFoundation/Metal renderer and macOS wallpaper-extension host.

The previous `NativeEngine` directory is retained only as an attributed MIT
reference and migration aid. It is not part of the LumaWall product.
